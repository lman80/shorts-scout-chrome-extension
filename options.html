Shorts Scout settings

Stored only in your browser (chrome.storage.sync). Never sent anywhere except Google's YouTube Data API.

e.g. 1000000, 10000000 counts videos over 1M and 10M.

Uses ~2 API units per short. Turn off to only fetch on Analyze.

How to get a free API key

  1. Go to console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. APIs & Services → Credentials → Create credentials → API key.
  4. Copy it here and Save. (Optionally restrict the key to the YouTube Data API.)
